Named entities: &amp; &lt; &gt; &quot; &copy; &nbsp; &mdash; &hellip;

Numeric entities: &#65; &#x42; &#8212; &#128512;

Not entities: &notanentity; &amp &#xZZ;

Backslash escapes: \* \_ \` \# \[ \] \( \) \{ \} \! \| \\ \< \>

Escaped emphasis \*is not emphasis\*, but *this is*.

An escaped backslash before an asterisk: \\*this is emphasised\\*.

A literal ampersand in a URL: [query](https://example.com/?a=1&amp;b=2)

Entities inside code are **not** decoded: `&amp; &lt;`

Entities inside a fence:

```html
&amp; &copy; &#65;
```
